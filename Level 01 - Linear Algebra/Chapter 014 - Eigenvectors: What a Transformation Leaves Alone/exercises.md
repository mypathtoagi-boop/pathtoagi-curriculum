# Chapter Exercises

Exercises should progress from understanding to research behaviour.

## Level 1 — Explain it
Explain the idea in plain language without equations.

## Level 2 — Calculate it
Solve a tiny numerical example by hand.

## Level 3 — Predict it
Predict code output, model behaviour, tensor shapes, or graph movement before running anything.

## Level 4 — Break it
Deliberately change an assumption or parameter and explain what fails.

## Level 5 — Build it
Implement the core mechanism from scratch before using a high-level library.

## Level 6 — Investigate it
Form a hypothesis, design an experiment, compare alternatives, and explain the evidence.
