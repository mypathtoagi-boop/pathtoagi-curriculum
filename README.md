# PathToAGI — the curriculum

### From Class-7 intuition to research-level AI — one connected path, no prerequisite maze.

Every chapter answers the question the previous one left open. Start at
[Level 00, Chapter 001](<Level 00 - What does learning mean/Chapter 001 - What Does It Mean for a Machine to Learn/blog.md>)
and read forward.

## The levels

- **Level 0 — What does learning mean?**
- **Level 1 — The language of AI: Linear Algebra**
- **Level 2 — The mathematics of change**
- **Level 3 — Probability and uncertainty**
- **Level 4 — Classical machine learning**
- **Level 5 — Doing machine learning honestly**
- **Level 6 — Neural networks from first principles**
- **Level 7 — Training deep networks**
- **Level 8 — Computer vision**
- **Level 9 — Sequences, language and Transformers**
- **Level 10 — Generative AI and foundation models**
- **Level 11 — Retrieval, tools and agents**
- **Level 12 — Reinforcement learning**
- **Level 13 — Research literacy**
- **Level 14 — Production AI and MLOps**

Each chapter folder holds `blog.md` — the lesson — and `exercises.md`.

## How to work a chapter

1. Read the story before touching the equations.
2. Recalculate the smallest numerical example by hand.
3. Predict each result before you accept it.
4. Change one variable and break it deliberately.

Reading is not enough. The exercises are the course.
